# Changelog

## 0.1.0

Prima versione. Regole per tenere piccolo, stabile e coerente il prefisso di un agente (file
sempre caricato + description delle capacità on demand) e script `prefix_check.py` che le
verifica su percorsi arbitrari: `--l0` per i file sempre caricati, `--capabilities` per le
cartelle delle capacità, `--budget`, `--strict`, `--hash`.
